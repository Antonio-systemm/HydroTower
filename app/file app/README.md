# HydroTower App

Applicazione Flutter Android per il monitoraggio e il controllo
di una torre idroponica HydroTower.

## Apertura con Android Studio

1. Aprire Android Studio.
2. Selezionare Open.
3. Scegliere la cartella che contiene pubspec.yaml.
4. Eseguire flutter pub get.
5. Consultare CONFIGURATION.md.
6. Collegare un dispositivo Android.
7. Eseguire flutter run.

## Funzioni principali

- visualizzazione dei sensori;
- storico delle misurazioni;
- report della torre;
- impostazioni;
- comando della pompa;
- notifiche;
- supporto WireGuard;
- modalità semplificate;
- comandi vocali e accessibilità.

## Sicurezza

L'app può inviare comandi a una pompa attraverso il backend.
Prima dell'utilizzo verificare sempre il circuito, il sensore
dell'acqua e i limiti di sicurezza.
